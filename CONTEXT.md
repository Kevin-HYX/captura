# Captura

Standalone browser extension for capturing human web workflows as evidence packages. Not an automation runtime — Captura observes and records, nothing more.

## Language

**Captura**:
The product: a Chrome/Edge extension plus a ZIP reader for human web-workflow evidence.
_Avoid_: Motion Recorder, Workflow Recorder, Ligentia Workflow Recorder

**Evidence Package**:
The ZIP a capture session exports: summaries, indexes, screenshots, DOM, and raw events.
_Avoid_: Flow Package, plugin, recording dump
